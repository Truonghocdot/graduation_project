# Mobile apps

Hai ứng dụng Flutter dùng chung backend nhưng có vòng đời nghiệp vụ riêng:

- [Khách hàng](client/README.md): đăng ký, chọn dịch vụ, chọn địa chỉ, nhận báo giá, tạo và theo dõi yêu cầu.
- [Tài xế](driver/README.md): đăng ký đối tác, KYC, bật online, nhận và hoàn tất chuyến.

Tài liệu chi tiết luồng đặt dịch vụ của khách hàng nằm tại [customer-booking-flow.md](client/customer-booking-flow.md).
